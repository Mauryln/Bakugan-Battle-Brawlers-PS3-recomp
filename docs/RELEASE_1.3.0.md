# Bakugan Recomp v1.3.0

- El juego mantiene 30 FPS nativos. FSR 3.1 puede presentar hasta 60 FPS mediante
  interpolación en combates compatibles.
- El instalador puede actualizar una instalación existente sin volver a copiar
  la ISO. La reparación desde ISO admite archivos instalados de solo lectura.
- Las opciones de pantalla incluyen ventana, sin bordes y pantalla completa
  mediante DXGI. F11 alterna entre ventana y sin bordes. La salida conserva 16:9.
- F12 muestra métricas de presentación y configuración durante el juego.
- El panel de controles incluye una imagen interactiva del mando y los ajustes
  de Sixaxis. La imagen se distribuye junto al launcher.

Extrae todo el ZIP antes de ejecutar el instalador. Para abrir el launcher
portable, ejecuta BakuganLauncher.exe dentro de la carpeta payload.
